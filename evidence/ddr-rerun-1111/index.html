Confirmed bug: near-coincident layer transitions

The full simplification replay of three captured iCE/Pi +1V5 routes fails when via merging cannot find an exact XY layer transition. The discrepancy is about 1.3e-12 mm. Normalizing stitched routes with the existing Pipeline 9 canonicalizer before simplification resolves the exception and preserves the input geometry. The native repro includes 54 surrounding pads. Its five distinct input via positions consolidate to one shared position after successful simplification.
