One electrical net. Many routed branches.

This page follows a connection from Simple Route JSON through merging and point-pair generation. The key idea: __rootConnectionNames records every original electrical identity represented by a connection.

Input: identity is local

Each connection knows its own name. Root metadata is optional at this boundary.

Connection A

{ name: "A", points: [p0,p1] }

Connection B

{ name: "B", points: [p1,p2] }

Union: geometry reveals connectivity

p1 appears in both connections, so DSU places A and B in one component.

find(A) === find(B) // true

Merge: preserve every root

Because neither input declares roots, their names become roots. The result cannot lose either electrical identity.

{ name: "A__B", __rootConnectionNames: ["A", "B"], pointsToConnect: [p0, p1, p2] }

Split: route manageable branches

The MST creates two point-pair jobs. Their names are operational; the root array is electrical lineage.

A__B_mst0 roots: [A,B] p0 → p1A__B_mst1 roots: [A,B] p1 → p2
