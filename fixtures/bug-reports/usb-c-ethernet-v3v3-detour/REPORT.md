# V3V3 rectangular detour above the RJ45 mounting hole

The USB-C Ethernet board produces a small rectangular detour on its 3.3 V
power branch feeding the RJ45 LEDs. This is not a differential pair, and no
length-matching constraint is declared for this power connection.

The detour is near x=15.75–16.55 mm, y=-3.50–-2.65 mm. In the full-board
snapshot it is the small upward bump on the thick red trace at the lower right,
above the large mounting-hole obstacle. The larger bend around the hole must
remain; the small additional bump is the behavior under investigation.

## Reproduce

```sh
bun install --frozen-lockfile
bun test tests/repro/usb-c-ethernet-v3v3-detour.test.ts --timeout 9999999
```

Captured from tscircuit 0.0.2815 / core 0.0.2124 / autorouter 0.0.967.
The inputs retain the complete 52 × 28 mm, two-layer board's obstacles and
connections. `signals.srj.json` is phase 0; `ground-connections.json` contains
phase 1 connections. Bounds, obstacles and routing options are identical in
the captured phases. The test uses freshly solved phase-0 copper as phase-1
input and clears the phase-0 pair constraints, exactly as core does. The
detour must be generated by the solver rather than loaded from the fixture. No TSX or core dependency upgrade is needed to replay
the autorouter input.

## Actual and expected behavior

The detour appears after phase 0 and remains after phase 1. Both phases solve.
The final full-board snapshot is
[here](../../../tests/repro/__snapshots__/usb-c-ethernet-v3v3-detour.snap.svg).

Expected: simplify the extra bump if a shorter replacement preserves all
trace, pad, hole and board clearances. Root cause and the safety of a specific
replacement segment are not yet established. This report does not remove the
detour or claim an electrical failure.

The snapshot's relaxed DRC count covers the repository's benchmark checks.
It is not a fabrication sign-off or a differential-pair length-skew check;
the original board still has three separately reported pair-length errors.
