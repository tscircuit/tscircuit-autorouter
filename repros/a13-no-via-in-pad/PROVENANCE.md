# Native Allwinner A13 DDR: forbidden repair vias

The regional repair stage can clear electrical DRC errors by moving a via into its
own signal pad, even when the board disallows via-in-pad. The same-net exemption
makes that candidate look electrically clean, but it violates the board's
manufacturing constraint.

This is the native A13 circuit used in core #5059/#5060, rendered through
`tscircuit@0.0.3052` / `@tscircuit/core@0.0.2251` with this checkout's Pipeline 9.
It retains all 20 component placements, 369 SMT pads, nine thermal plated holes,
and 96 DDR source paths. Eight paths for D0–D3 are selected through RN4/RN1.
The board explicitly sets `isViaInPadAllowed={false}`. No pad, placement, trace
width, via size, or clearance is changed to help routing.

Native source: [sbc_allwinner_a13/module.kicad_pcb](https://github.com/vd-rd/sbc_allwinner_a13/blob/8973c32c64349515da64e268cc03ea8c0789ca2a/hardware/module.kicad_pcb).
PCB SHA-256: `563b646fbd1f021c43a337798882e54ed024c39823280f8b93ddc59c9aa7cb33`.
`source-data.json` and the native TSX component renderer preserve that source
geometry in board-world millimetres (+X right, +Y top, +Z above).

Run `bun repros/a13-no-via-in-pad/render.tsx` from the repository root.
`board.svg` and `ram-detail.svg` are generated by `circuit-to-svg` from the actual
core-rendered Circuit JSON. The latter zooms in on the RAM's D1/D2/D3 escapes.
The script also writes raw circuit/input/output JSON for inspection.
`result.json` records connectivity, via-in-pad findings, and other clearance
errors. The SVGs omit error overlays; they do not imply a DRC-clean result.

Before the fix, all eight paths connect but three newly introduced vias drill
into RAM pads. After the fix, all eight still connect and none drills into a pad.
Seven ordinary clearance errors remain in the fixed eight-path output; this is
not a complete or manufacturing-ready DDR route.

For the control, run
`bun repros/a13-no-via-in-pad/render.tsx 0,1,4,7,8,9,12,13,15 /tmp/a13-control`.

The compressed test inputs are captured core routing inputs. The separate
18-path control selects bits 0, 1, 4, 7, 8, 9, 12, 13, and 15 without changing
any copper geometry. It is already clearance-clean before the fix and remains
so after it. The policy regression also exercises the default setting and an
explicit `allowViaInPad: true` opt-in.
