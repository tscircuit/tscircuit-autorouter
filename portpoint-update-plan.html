Update Rules

  • When a solver clones or rehydrates a PortPoint, it must preserve prevPortPointId and nextPortPointId.
  • When a pipeline synthesizes new port points, it must either compute chain links intentionally or leave them undefined without dropping surrounding links.
  • Any subproblem builder that slices a node into a smaller node must retain chain metadata on copied port points.
  • The center-connection regression test must keep passing after the chain metadata is introduced.
