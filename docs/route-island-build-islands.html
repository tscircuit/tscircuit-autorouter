General idea: for one connection, this function groups regions that touch through shared port points, splits them into connected groups, and turns each group into a route island.

private buildIslandsForConnection(
  connectionName: string,
  regions: RouteIslandRegion[],
) {
  const sharedPortToRegionIndexes =
    this.buildSharedPortToRegionIndexes(regions)
  const neighbors = this.buildRegionNeighbors(
    regions,
    sharedPortToRegionIndexes,
  )
  const components = this.getConnectedRegionComponents(regions, neighbors)

  return components.map((component) =>
    this.buildIslandFromComponent(
      connectionName,
      component,
      regions,
      neighbors,
    ),
  )
}

Builds a lookup table. For each shared port point, it records which region indexes contain that port point.

General case: if region 0 and region 2 both touch the same port, the map remembers that this port belongs to regions 0 and 2.

Converts the shared-port lookup into a neighbor graph. A region becomes a neighbor of another region when they share a port point.

General case: if region 0 shares a port with region 2, then region 0 lists region 2 as a neighbor, and region 2 lists region 0.

Short version

This function does not route traces by itself. It organizes regions for one connection into connected groups. Each connected group becomes one route island.
