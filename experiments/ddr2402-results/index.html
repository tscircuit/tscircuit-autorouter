Selected issue: stitching bypasses a routed via path

On the iCE/Pi CPUX net, the greedy stitcher prefers an exact-XY jump from the top layer to inner copper over a short planar splice to an existing via. Following the inner fragment then returns to the top layer and leaves the bottom-layer C15.2 terminal unreached. The input contains the correct routed transition. The latest release rerun produces exactly the same stitching constructor input as the repro capture. The fix gives a locally accessible routed transition priority over an unplanned cross-layer hop. Existing via sites and declared transition anchors keep their priority; distant vias and internal via loops cannot divert a valid terminal join. The focused repro uses the original 24 fragments and 32 nearby pads. It now runs native trace simplification after stitching succeeds, asserting both terminal layers and the resulting via positions. Its checked-in SVG changes from 1/2 terminals and 3 via sites to 2/2 terminals and 1 via site. The crop’s remaining relaxed DRC findings are computed and displayed: 12 → 6. Method and remaining work

Each TSX contains the complete board, including original component placement, pad geometry and net membership. All original routed tracks, vias and saved poured copper are removed. New pours come from authored plane intent. Every before/after full-board input starts with zero copper elements; geometry and net-membership audits pass for all 24 full-board cases. Physical findings are shown with every native PCB SVG. Phased mode routes plane escapes, DDR byte lanes and remaining signals; fanout mode exercises the current fanout solver first. Complete success requires every routable net connected, routing finished and zero physical findings.

Budgets are unchanged: 600 seconds routing, 660 seconds process, 180 seconds audit. Phased/fanout runs share a worker at concurrency 2; the separate controlled OrangeCrab pair runs sequentially. Original DDR controls run separately. Frozen workflows and lockfiles are included. Native outputs are the actual emitted copper, including partial results.

The latest release still exposes independent blockers: ButterStick dense prepared pathing, i.MX6 joint DRC repair, H616 surface approach geometry, fanout escape capacity and large-plane time budgets. The stitching fix was selected because it removes a reproducible terminal-layer failure and recovers the complete captured iCE/Pi phase without relaxing terminal, clearance or DRC checks. The six full boards still require further routing work.
