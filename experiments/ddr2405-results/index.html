Measured results

All six full circuits were rerouted fresh using the latest published stack at the start of this analysis. Neither routing mode completes a clean full board: 0/6 before and after. Phased routing retains 29/1,580 complete nets and 827 physical findings; fanout retains 22/1,580 complete nets and emits no signal traces. The selected fix removes a reproduced clearance violation during exact repair of earlier copper, with fewer vias, while preserving these board results.

Every full-board run starts with original copper removed: 49,583 tracks, 4,706 vias and 685 zones. Authored pour intent is rebuilt fresh. Component and pad counts, pad positions and net memberships are audited. Benchmarks use 8-vCPU ARM Blacksmith workers and two routing processes per board, with a 600-second routing budget, 660-second process limit and independent 180-second audit.

Accepted fix

Exact repair did not receive the cached physical reference checker during copper handoffs. The fix enables its acceptance guards when native preloads or explicit PCB-port connections supply the earlier copper context. Circuit-error priority is preserved, and the joint checker continues validating fixed copper. Plane escape anchors require plane geometry before this reference guard can apply.

The existing SEPIC repro keeps its pinned tscircuit 0.0.3186 runtime constant across both sides. Its VCC/GATE trace-clearance error falls from 1 to 0, with 11.1% fewer vias (18 → 16). The GATE route stays on top, removing two layer transitions. The measured same-layer VCC/GATE gap changes from 0.049 mm to 2.252 mm against the 0.1 mm rule.

All six original DDR controls pass all 310 nets before and after with zero physical findings and identical trace counts, via counts and wire lengths. Paired pipeline 9 / dataset 18 passes 16/16 before and after, with identical native PCB SVG hashes and 212.25 average vias. Its mean time changes by +0.31%; this is a single paired run and does not establish a speed improvement.

Analysis and remaining blockers

The full-board completion bottlenecks remain: dense BGA fanout cannot escape within the available boundary on iCE/Pi, i.MX6 and ButterStick, while other fanout runs exhaust their budget. In phased routing, ButterStick exhausts port-point pathing iterations; H616 fails the DDR bus solver's surface-approach geometry/matching check; OrangeCrab, Glider, i.MX6 and iCE/Pi exhaust the routing budget, with repeated joint DRC work prominent in captured timings. The broader plane-continuity correction reduced false findings but worsened Glider's actual copper, so it was rejected. The scoped reference guard addresses a demonstrated physical correctness issue; it is not a full-board completion improvement.

Rejected candidate

The broader external-plane correction was rejected after Glider physical findings rose from 42 to 52. It is excluded from the accepted fix and all after panels on this page. Measured rejection record
