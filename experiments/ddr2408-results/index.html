Measured improvement: preparation time

ButterStick's isolated preparation stage falls from 90.256 s to 18.047 s: 80.0% less time, using the median of three serialized runs per revision on the same Blacksmith worker. Every run returns the same complete graph hash. The existing search now skips repeated capacity-node expansions that cannot improve a candidate; it still revisits a node when a cheaper path reaches it.

Remaining blockers

The optimization preserves the graph; it does not resolve dense fanout escape failures, ButterStick's port-point iteration limit, H616's bus surface-approach geometry/matching failure, or the long joint DRC and cleanup work on larger full boards. All six full circuits remain incomplete. More published partial copper does not establish a clean board.

Reproduce

Use Bun 1.4.3 on Blacksmith. Checkout core at f8f2ed3273cea45e70e78ddc7470ba9fc47a1e73. Checkout the router at bfc6509a20959b11ebdea7e38d7fb5fe0fef2097 for before or 811f04e85ba271222dc7beb50b9751ee2a3a916f for after, then run:

cd full-board-models
bash reproduce.sh /absolute/router /absolute/core /absolute/results
