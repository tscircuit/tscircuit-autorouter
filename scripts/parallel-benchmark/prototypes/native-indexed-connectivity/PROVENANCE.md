# Dormant indexed connectivity memo proof

This Bun/Node functional prototype is not imported by a production pipeline or a public barrel. It constructs the current native `Pipeline9MemoizedAutoroutingDrcEngine` exactly once and temporarily replaces only its electrical predicate during an eligible original synchronous `evaluate`. The default engine and joint solver are unchanged.

The derivative engine is based on MIT high-density-repair03 commit `e16df6c48efed49406cf45df49fd933d3141973d`. The only engine prerequisite is an internal source-initialized descriptor reader for SpatialHash and the literal Engine constructor/prototype. Its module-completion identity records stay private; each reader receives fresh arrays and descriptors. Engine methods must retain those original identities, since exact source text can be recompiled with different lexical bindings. The reader does not construct an engine, evaluate geometry or activate a memo.

Admission deliberately has a module-first boundary: the engine/metadata module must first initialize under native Object/Reflect reflection and the original function-source printer. Arbitrary replacement of those reflection globals or that printer before original library initialization is outside this proof. The module retains its original `Function.prototype.toString` reference through captured reflection on a local literal function, without reading a global Function getter. Fresh reader copies cannot replace that private reference. Both pinned JavaScript fingerprints and complete canonical native-function-body checks use the held printer. After that boundary, the helper rejects pre-helper-import or later modified collection methods/constructors, source printers, known Proxy/bound functions, engine and ConnectivityMap methods, imported geometry functions, accessors, custom callbacks and Proxy data without invoking those observers. A JavaScript function containing a `[native code]` string does not pass the complete native-body check. Iterator `next`/iteration functions are checked; Bun's anonymous iterator tag accessors are not used by this span and are only checked for later identity changes.

`hasPinnedNativeIndexedDrcFunctionSources.ts` holds private exact function-source fingerprints for the engine and ConnectivityMap constructors/prototypes and all math-utils, transformation-matrix, via-layer and layer-name exported functions. These are secondary source-runtime compatibility checks, not identity proof or a portable bundled-runtime contract. A source mismatch selects the original engine before an optimized span. Licenses for the copied source fingerprints are included alongside this file: math-utils 0.0.36, transformation-matrix 3.1.0, connectivity-map 0.0.19 and pinned repair03.

The owned engine is never returned. Its original constructor input object graph is retained privately and revalidated with current input/option/trace roots before each evaluation. This covers arrays and connMap objects captured by the native constructor even after a caller replaces a visible field. Only data-only graphs with native prototypes and complete builtin/geometry contracts enter the synchronous span. No callback can interleave a connection mutation in that span; mutations between evaluations remain live and get a new memo. An unsupported constructor or evaluation permanently retires memo eligibility before calling native code, because a native callback could retain the engine and mutate its private caches even after restoring public hooks.

The memo is keyed by ordered actual left/right IDs. It preserves the native same-name fast return, false answers, aliases and asymmetric `areIdsConnected` behavior. Its first miss calls the original predicate at the original native position. It holds at most 65,536 pairs per evaluation; additional misses still run the original predicate. Publication order, centers, native geometry checks and run counters are unchanged. `finally` removes the private instance override; an invariant/retirement error is loud, and no thrown native error triggers a retry.

The durable work proof uses 17 saved sample015 native reference geometries reconstructed with the original indexed-engine clearance/cell/connMap policy. These are not all remote candidate evaluations. Each record compares exact errors, order, centers and all native run counters against a separate persistent same-source native engine. Additional cases prove asymmetric actual IDs, shared net-array aliases, live between-call map mutation and the 65,536-entry bound. 37 fresh-process observer cases cover pre-helper wrappers, source-printer methods/getters, native-marker forwarding functions, identical-source Engine methods with counterfeit closures, collection-global getters, deleted globals, inherited descriptor metadata getters, inherited numeric array accessors, bound/Proxy methods/constructors, class/map/numeric hooks, forged copied SpatialHash metadata/source-printer references, later reflection changes, data getters/Proxies and replaced original retained aliases/maps. The retirement case restores public hooks after capturing the engine, then corrupts only the private geometry cache; later evaluation remains native with identical callback observations. Bootstrap array slots and copied SpatialHash slots use captured own-property definitions, so inherited array setters do not run during eligibility import. Intrinsic constructor/prototype capture uses own data descriptors, so collection-global accessors are rejected without invoking their getters.

The guarded memo removes 5,578,630 of 6,194,769 nontrivial predicate executions in that 17-record reconstruction. Admission also scans 223,168 objects and performs 5,096,874 property checks. The guard cost is material; these are operation counts, not a speed claim or activation recommendation. A narrower closed native readset would need a separate proof.

Reproduce locally as functional checks:

```sh
bun test --timeout 9999999 tests/solvers/native-indexed-connectivity-memo-dormant-proof.test.ts tests/solvers/native-indexed-connectivity-memo-observer-boundary.test.ts
```

The fixture preserves own undefined and negative-zero primitives with explicit tags. Identity aliases are tested separately. Raw routed outputs and timings are not included in the compact proof report.
